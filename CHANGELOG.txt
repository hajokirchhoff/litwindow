November 2026 - version 1.5.6
	Debug libraries get a 'd' postfix (lwbased.dll/.lib, lwodbcd.*, lwwxd.*) so that
	Debug and Release builds no longer overwrite each other. Release names unchanged.
November 2026 - version 1.5.5
	list mediator columns().add() accepts pointers to data members and const member
	functions of a base class of the value type (previously not deducible, also on MSVC).
November 2026 - version 1.5.4
	Headers now parse with clang/clang-cl (template<> for converter_enum::my_adapter,
	specialisation order in IMPLEMENT_ADAPTER_TYPE_ds, no dllexport on
	prop_type_object::__return_registrar under clang, typename in list mediators).
	Debug builds no longer write dump_lwlog.txt into the current directory;
	set the environment variable LWL_LOG_DUMP_FILE to a file name to enable it.
October 2026 - version 1.5.3
	Installed headers no longer request the boost-style auto link names
	(e.g. lwbase-vc143-mt-gd-x64-1_0_0.lib) and describe the installed
	libraries (shared or static) themselves, so MSBuild/vcxproj consumers
	of the vcpkg package need no extra defines or linker settings.
	cmake --install now installs a generated litwindow/build_config.h
	(from cmake/build_config.h.in) over the empty in-tree default.
	Fixed C4996 (wcscpy) in dataadapterimp.h for consumers.
	Known: including litwindow/odbc headers before wx headers gives C4005
	for the _() macro; include the wx headers first.
January 2009
	Restarted litwindow development on sourceforge.
	The library has been improved over the years, but the development was
	not reflected on the sourceforge page.
